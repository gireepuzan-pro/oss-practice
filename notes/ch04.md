# Chapter 4 – Git Basics

## What is Git?

Git is a version control system that tracks changes in files and projects.

## Three States of Git

1. Modified – A file has been changed.
2. Staged – Changes are selected for the next commit.
3. Committed – Changes are saved in Git history.

## Important Git Commands

- git status – Check the current repository status.
- git add – Stage changes.
- git commit – Save changes in Git history.
- git push – Upload commits to GitHub.
- git pull – Download changes from GitHub.
- git log --oneline – View commit history.
- git clone – Copy a repository from GitHub.

## What I Learned

Git helps developers track changes, manage project versions, and collaborate with others.
